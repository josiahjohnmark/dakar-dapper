# Dakar Dapper — Luxury Men's Fashion Line

> **The Art of Dressing Well**  
> Curated luxury menswear and accessories designed with heritage craftsmanship and contemporary elegance.

---

## 🌟 Overview

**Dakar Dapper** is a modern, responsive luxury e-commerce web platform for premium menswear, footwear, and accessories. Built with clean semantic HTML5, modern vanilla CSS design tokens, and modular vanilla JavaScript.

---

## ✨ Features

- **Responsive Luxury UI**: Tailored for mobile, tablet, and desktop viewports with fluid typography and micro-animations.
- **Curated Catalog**: Filter products by the categories set in the admin.
- **Quick View Modal**: Interactive product detail preview with color swatches, size selectors, quantity controls, and feature tabs.
- **Slide-out Cart Drawer**: Real-time cart calculations with a free-shipping progress tracker and direct checkout.
- **Wishlist Drawer**: Save favorite items and transfer directly to cart.
- **Search Overlay**: Instant keyword search and quick-tag filtering.
- **Concierge WhatsApp Integration**: Floating widget with interactive support chips, instant replies, and direct WhatsApp messaging.
- **Favicon & Brand Identity**: Custom cropped 3D metallic **DD** mark and high-resolution favicons across all devices.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/josiahjohnmark/dakar-dapper.git
   cd dakar-dapper
   ```

2. **Open in browser**:
   - Simply double-click `index.html` or serve with any local HTTP server:
     ```bash
     npx serve .
     ```
